Datenschutz auf dieser Website

Diese Website setzt keine Cookies. Wir zählen Seitenaufrufe mit Cloudflare Web Analytics: ohne Cookies, ohne Fingerprinting und ohne Profile einzelner Besucher. Gezählt werden nur die aufgerufene Seite, die verweisende Seite, das Land, Browser und Gerätetyp. Tipps auf die App-Store- und Google-Play-Buttons zählen wir selbst: je Tipp der Zeitpunkt, der Store, die Seite, das Land, die Art des Geräts und Browsers, die Sprache, woher der Besuch kam (verweisende Seite oder Kampagnen-Link) und welche Seiten davor wie lange angesehen wurden. Diese Angaben über den Besuch liegen nur im Tab (sessionStorage, kein Cookie) und gehen nur mit einem solchen Tipp an uns. Wir speichern keine IP-Adresse, keine Kennung und nichts, womit sich eine Person erkennen ließe. Gehostet wird die Seite bei GitHub Pages, das beim Aufruf technisch nötige Server-Logs (z. B. IP-Adresse) verarbeitet. Die Datenschutzerklärungen unserer Spiele findest du auf der jeweiligen Spielseite.

This website sets no cookies. We count page views with Cloudflare Web Analytics (no cookies, no fingerprinting, no visitor profiles), and count each tap on the store buttons ourselves: when, which store and page, the country, the kind of device and browser, the language, where the visit came from (the referring site or a campaign link) and which pages were seen before it and for how long. The visit details stay in the tab (sessionStorage, no cookie) and only reach us with such a tap. We keep no IP address, no id and nothing that could tell who it was. It is hosted on GitHub Pages, which processes the server logs needed to serve it.
